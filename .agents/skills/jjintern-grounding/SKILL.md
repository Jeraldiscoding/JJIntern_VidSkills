# Ground the creative

Use for JJIntern feature claims, brand choices, asset selection, or product-truth updates.
Required inputs: intended audience, claim or journey, destination, and available product/assets.
Infer reversible editorial choices; record any missing evidence instead of inventing it.

## Read

- [Product truth](../../../creative/product/brief.md) and [evidence register](../../../creative/product/evidence.md).
- [Brand guide](../../../creative/brand/guide.md) and [tokens](../../../creative/brand/tokens.json).
- Read the [claims rules](../../../creative/claims/README.md) only when a factual claim needs checking.

## Workflow

1. List exactly what the creative would assert or depict. Separate existing functionality, public-site assertions, owner descriptions, unknowns and verified plans.
2. Inspect the relevant source/capture. Public controls do not prove successful interactions; marketing copy does not prove operation. This workspace initially had no app source.
3. For a demo, perform the real input and inspect its result in a clean public session or an authorised test account. Preserve the source, date and limitations.
4. Select authentic assets and existing tokens. Keep proposed marketing treatments separate from observed identity; preserve real UI and logo proportions.
5. Update the evidence register and relevant claim records when new facts are actually established. Attach exact application source paths only when source exists.
6. Return a compact grounding note: permitted wording/journeys, selected assets, source IDs/dates, prohibited inferences and precise missing inputs.

## Gates and missing evidence

No fabricated feature, vacancy, employer relationship, interface, logo or outcome. Illustrative homepage roles are not live vacancies. A company tile is not proof of hiring.
Use the last verified fact, remove the dependent claim, or choose a verified public journey while waiting for evidence. Do not call an unknown feature planned. Request only an essential missing asset or test-account capture; finish independent work.
