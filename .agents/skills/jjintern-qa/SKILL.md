# Review the idea and the artifact

Use for JJIntern creative QA, claim verification, or a pre-export/release review.
Required inputs: exact script/brief, intended platform, artifact if produced, evidence/claim IDs, asset manifest and checks already performed.

## Read

- [Rubric](../../../creative/qa/rubric.md), [claims rules](../../../creative/claims/README.md), [ledger](../../../creative/claims/ledger.json), and [claim template](../../../creative/claims/template.json).
- [Product truth](../../../creative/product/brief.md), [brand guide](../../../creative/brand/guide.md), and relevant [platform guidance](../../../creative/references/platform-guidance.md).
- For pay-led or best-company content, use [career content](../../../creative/playbooks/career-content.md): check the first-frame pay context, annual-to-monthly arithmetic, ranking basis and useful reason for every company.

## Workflow

1. Review the premise without effects: specific hook, interesting student relevance, credible payoff, natural product link and one appropriate CTA.
2. Map every material fact to evidence. Reopen time-sensitive primary sources near release; distinguish employer-confirmed pay from estimates, annualised rates from placement earnings, and programme existence from active applications. An objective ranking needs comparable data and a defined universe; an editorial shortlist needs an explicit criterion and supported reasons.
3. Inspect actual assets/artifact rather than trusting the script. Check meaningful action/results, purposeful motion, every panel/shot's information gain, human copy, authentic UI and distinctness from recent posts.
4. Inspect privacy, rights, missing glyphs, clipping, contrast and readable qualifications. Watch video muted; view carousels in order and individually. Record phone/upload-preview checks as pending if not performed.
5. Score each rubric criterion with observed evidence and a concrete repair. Any hard failure blocks release regardless of other scores; revise a weak idea before adding effects.
6. Deliver findings by impact, exact repair locations, updated claim records when warranted, performed/pending checks, and separate concept/asset/artifact/release statuses.

## Gates and missing evidence

Hard failures include fabrication, salary without context, an unresolved hook, private data, unreadable/clipped essentials, deceptive vacancies/destinations, missing rights, and repeated slide-card animation presented as finished product motion.
No scores predict views or certify quality. Never mark a check passed because a template names it. If evidence or the export is missing, review what exists and state the precise gap; remove the dependent claim or hold release while useful local revisions continue. QA does not publish content.
