# Workspace navigation

Read [creative/AGENTS.md](creative/AGENTS.md) and [owner creative direction](creative/CREATIVE-DIRECTION.md) before creative work.

- Current projects live in [creative/projects](creative/projects/README.md); start from each project's README.
- Earlier work lives in [creative/archive](creative/archive/README.md). Archived approval gates and timing instructions are historical when superseded.
- Keep shared guidance, brand assets, evidence and scripts at their established paths; project skills depend on them.
- Use [README.md](README.md) for the latest video, caption and folder map. Add new work to a named project rather than loose files at the workspace root.
