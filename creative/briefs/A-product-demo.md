# A — Know the company? Start here.

Prepared 2026-10-17. Audience: Singapore students with a target employer but no concrete search action. Format: 12-second vertical video, 1080×1920, 30 fps. One useful action: find a company in the real public directory. Destination: **JJIntern.com/companies**. This is an actual tested public product journey, not an authenticated tracker demonstration.

Intended first placement: **organic Instagram Reel**. TikTok/Shorts are possible adaptations, each with its own current placement preview. Organic Instagram specification verification remains pending as recorded in platform guidance; this is a working master, not an upload certification.

## Selection before animation

Three hooks, each with an honest payoff:

- **“Know the company? Start here.”** → a real company-name search and matching tile. Selected: specific action, strong evidence, minimal claim burden.
- “Find the company. Then check the roles.” → company search followed by explanation that role availability needs a fresh check. Alternate opening; do not imply an application is completed.
- “Your next search starts with one name.” → type a company name and narrow the directory. Less literal; reserve for a copy test.

Concepts compared (0–2 each for interest, evidence, relevance, product connection, feasibility): real company search **1/2/2/2/2**; save-to-tracker walkthrough **2/0/2/2/0**; decorative rotating directory screenshots **0/2/1/1/2**. Company search wins because a real action changes the screen and the audience can repeat it. Saving/tracking needs a sanitised account and a persisted-state test. Decorative rotations do not explain an action.

Selected mechanism: **one action, visible consequence**. Start with the question, establish the directory, type Microsoft into the actual search field, hold the narrowed result, and invite the viewer to try their own company. Microsoft is an example directory entry, not a claim of affiliation or a current vacancy.

## Shot list

Main heading 88 px, supporting copy 46–48 px, provenance 36–42 px in the 1080-wide master. Keep the real input and result in a stable crop. The proof renderer includes this exact sequence.

From the first product reveal at 0.5 s through the CTA, keep **`Company directory.` / `Check current roles separately.`** beside the crop at 42 px. This prevents transient role-count badges within real UI from being mistaken for an employer-confirmed vacancy claim.
