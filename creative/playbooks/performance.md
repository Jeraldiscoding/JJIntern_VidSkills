# Learn without promising reach

Before production write one hypothesis: audience + change + observable outcome. Example: “For students who already have a target employer, a real search action will produce more qualified directory visits per reached viewer than an abstract organisation message.” This is a hypothesis, not a forecast.

Select one main outcome. The owner's **24 October 2026** career-picture brief prioritises **qualified JJIntern website visits and relevant directory/feed use**. Saves, source visits and swipe depth are supporting signals; an informative post that never gives a useful reason to visit has not met this brief. A different primary outcome needs a different brief. Account creation, role saves and application starts may be useful only if actual product analytics and event semantics are verified. No analytics instrumentation is installed by this folder.

Record the caption, destination, platform, publication time, format, slide count or runtime, hook, direction, audience, claim IDs and asset version in `qa/post-log.csv` or the linked project record where the current schema has no field. A locally rendered post is not a published post. Use campaign parameters only if the owner approves them and the destination accepts them; never include personal identifiers. Separate organic and paid distribution.

For each variant record reach/impressions as exposed by the platform, saves, shares, destination clicks, measured visits and verified downstream actions. For picture posts, add swipe depth or last-panel reach only when the platform reports them; watch-duration and automatic-timing metrics do not describe a manual-swipe sequence by default. For actual videos, use early retention, average watch duration and a stated completion definition when available. Counts can have different denominators; write the formula alongside rates. Unknown metrics remain unknown.

Compare the same platform/format and similar observation windows (house suggestion: 24 hours and 7 days, record exact dates). Test one major change, such as the first sentence; keep the evidence/payoff constant. Small samples, distribution differences, repeated viewers and attribution loss limit conclusions. Do not call a change a winner from a handful of views or promise a causal lift from an uncontrolled comparison.

Decision record: what happened, what the evidence supports, what remains uncertain, keep/change/stop, next variable. High views with low relevant use may be a weak result. A low-reach post can still reveal confusing copy. Feed actual lessons back into direction failure modes instead of creating rigid “viral formulas”.

For the owner's salary and company picture posts, start by testing the cover or the specific reason to visit while keeping evidence, body and destination constant. Proposed primary rate: measured JJIntern visits divided by reached viewers, only if attribution and both counts are available. Platform link clicks and first-party visits are separate observations; do not equate them. Use observed swipe depth and saves as context for whether the facts and CTA were encountered. Public competitor views cannot reveal retention, paid distribution, attribution or which creative choice caused reach. The owner's observation is a reason to run the test, not its result.
