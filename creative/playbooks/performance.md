# Learn without promising reach

Before production write one hypothesis: audience + change + observable outcome. Example: “For students who already have a target employer, a real search action will produce more qualified directory visits per reached viewer than an abstract organisation message.” This is a hypothesis, not a forecast.

Select one main outcome. For these briefs it is qualified JJIntern directory/feed use; employer-opportunity education may instead use source visits or saves, with JJIntern visits secondary. Account creation, role saves and application starts may be useful only if actual product analytics and event semantics are verified. No analytics instrumentation is installed by this folder.

Record the caption, destination, platform, publication time, length, hook, direction, audience, claim IDs and asset version in `qa/post-log.csv`. Use campaign parameters only if the owner approves them and the destination accepts them; never include personal identifiers. Separate organic and paid distribution.

For each variant record reach/impressions as exposed by the platform, early retention if available, average watch duration, completion definition, saves, shares, destination clicks, measured visits and verified downstream actions. Counts can have different denominators; write the formula alongside rates. Unknown metrics remain unknown.

Compare the same platform/format and similar observation windows (house suggestion: 24 hours and 7 days, record exact dates). Test one major change, such as the first sentence; keep the evidence/payoff constant. Small samples, distribution differences, repeated viewers and attribution loss limit conclusions. Do not call a change a winner from a handful of views or promise a causal lift from an uncontrolled comparison.

Decision record: what happened, what the evidence supports, what remains uncertain, keep/change/stop, next variable. High views with low relevant use may be a weak result. A low-reach post can still reveal confusing copy. Feed actual lessons back into direction failure modes instead of creating rigid “viral formulas”.
