## Evidence levels

1. **Owner supplied** — audience/problem context in the user's brief, retained in [brief.md](brief.md). Not an independent measurement.
2. **Observed public markup/style** — HTML, CSS, assets actually downloaded. A visible control or implementation rule is evidence of its presence, not its end-to-end operation.
3. **Observed public interaction** — requires a recorded input and completed result in a browser. Log exact states, failures, date, and screenshot/recording paths.
4. **Public-site assertion** — JJIntern marketing describes a behaviour; this audit did not test it. Never promote automatically to verified functionality.
5. **Source/test confirmed** — none at initial audit. Planned features also unknown; no roadmap supplied.
